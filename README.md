# Mark John Lucero — Death Lotus Portfolio

## Run locally
Open `index.html` in a modern browser. For best results, run a local static server from this folder:
- Python: `python -m http.server 8000`
- Then open `http://localhost:8000`

## Publish free
1. Create a public GitHub repository.
2. Upload the contents of this folder (keep the `assets` folder).
3. In GitHub, open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

The website is static and does not require a paid service or backend.

## Included source material
- Prelims: Death Lotus moodboard, icon, horizontal/vertical logos, badge, FreshSpin service proposal, flyer, and poster.
- Midterms: Brand identity poster and all four pages of Magazine Me.
- Finals: promotional video.
- Midterm online-banking design brief is preserved in `assets/midterm_online_banking_design_brief.docx` as supporting coursework material, not shown as a graphic-design portfolio artwork.

Original PDF/PNG files are retained in `assets/original_*`. Gallery thumbnails are generated page previews; original artwork files are linked from each project modal.
